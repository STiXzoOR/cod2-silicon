## Completion contract

The initial executable scope is the three hash-pinned owned Mac inputs in A0.
The first completion target is native Mac multiplayer, following the existing
source product. The user confirmed multiplayer first, then single-player on
2026-10-15. Shared recovery retains SP evidence; the second completion target
requires its own implementation and validation campaign.
Do not silently count MP source correspondence as an SP implementation or
substitute Windows execution evidence for Mac behavior without documenting the
difference. Other owned variants require provenance review and their own ledger.

A validated reconstruction requires all of the following for its declared scope:

- Account for every executable region, function, indirect dispatch target and
  required data object. Unknown reachable code and unresolved essential layouts
  block completion; heuristic padding labels and successful pseudocode do not
  resolve them.
- Reconcile every required implementation with original assembly/debug evidence.
  Keep i386 layout facts separate from LP64 objects, disk/wire formats and native
  platform replacements. Classify libraries and intentional replacements with
  explicit reasons, never as implicitly equivalent.
- Execute original instructions or original-process scenarios as independent
  behavioral oracles. Record input domains, outputs, state effects, numerical
  tolerances and modeled services. Preserve mismatches and unsupported cases.
- Verify deterministic gameplay, script VM, movement/combat, collision, loading,
  audio/voice, networking, demos and renderer/resource behavior. Cover map and
  lifecycle transitions, failure paths and long runs. Compare richer state than
  the existing quantized entity-only simulation hash.
- Pass native stock/CODX checks, the applicable legacy artifact comparison,
  deployment-compatible builds and live reference comparisons. Record exact
  source, binary, compiler, dependency and data identities for each result.

“Validated” is an evidence-backed claim over documented scenarios and domains,
not mathematical proof of equivalence for every possible input. No overall
completion declaration is permitted while required evidence is missing.

repeatability evidence but cannot substitute for original/native comparison.
