Updated 2026-11-05.

Mac 0x24b5a uses cofactor expansion and rejects absolute determinant below 0.0005; native incorrectly used Gauss-Jordan with a cutoff on each pivot. Native now accumulates the first-row determinant in Mac SSE order, computes signed minors, divides by that determinant and writes the transposed cofactors directly. Rejection leaves the result untouched; NaN continues as on Mac.

D3DXMatrixInverse is implemented in D3DXMath.c despite this ledger attribution. The parent authorized that single function. At Mac 0x23c46, affine eligibility is a bit test: negative zero takes the full inverse path. Both branches write determinant zero only after matrix output. The generic original ignores inverse failure and copies uninitialized stack storage. Native intentionally retains its existing defined input-copy fallback instead, with the input copied before any output stores. This explicit adaptation prevents a full equality verdict.
