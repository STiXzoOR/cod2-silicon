Native now follows its ordinary positive-capacity byte loop: discard LF without changing state, collapse spaces, turn the first CR into a space, emit two CR bytes for a subsequent CR, and preserve the separate space/CR state decisions. Native caps that exceptional pair and always terminates inside positive-capacity output; nonpositive signed capacities return without writing. These are defined storage adaptations, not equivalence for overflowing or negative-capacity inputs. Overlapping source/destination behavior and malformed HFS lengths are not certified.
