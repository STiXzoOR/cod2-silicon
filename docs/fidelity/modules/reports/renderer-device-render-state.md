The independent review found a concrete retained-context reset gap. Mac Reset releases its context at 0x19d85, creates a new one at 0x19e50, calls COpenGL Init at 0x19e94, and writes default stencil caches at 0x1a4f3–0x1a539. Native Reset keeps the SDL context; COpenGL Init disables stencil but did not restore its function, operations or write mask. A prior STENCILFUNC=1 therefore left GL_NEVER active behind the reset ALWAYS cache, and a later STENCILFUNC=8 was skipped. Native render-state initialization now explicitly restores ALWAYS/ref 0/read mask all ones, KEEP operations and the all-ones write mask.

The adjacent audit confirmed the same context dependency for fog color/start/end/density, point minimum/maximum/attenuation and sprite state, and the color-material mode. COpenGL Init already restores the other dispatcher defaults, including fog mode, point size, blend equations, alpha/depth state, polygon mode, shading, offset and light-model ambient. Lighting validation at original 0xe91a can enable color material without selecting its mode, so resetting only its enable cache also retained a stale mode. Initialization now restores its fresh-context FRONT_AND_BACK/AMBIENT_AND_DIFFUSE selection.
