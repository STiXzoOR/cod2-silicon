## Driver repairs

The normal native route now runs the original fixed/FVF or programmable validator chain, instead of rebuilding arrays and transforms from stride/material guesses. Mac 0x120a6 validates modelview first. Base changes update the retained base word. Normal and scanned low/high bounds add base exactly as 0x120fc–0x12117 and 0x12203–0x12233 do. Raw ushort indices still begin at `data + startIndex*2`; range hints include base separately. The original always consumes ushort indices even if the buffer records another format. Validation receives `high-low+1`, while raster receives `base + (high-low+1)`, rather than `high+1`. Packet range arithmetic stays in the reviewed widened provider.

Mac 0x12124 forces transformation validation on every call. Transformation/raster flags clear only after raster validation, and the common return at 0x1218f resets the draw byte. Raster can clear that byte without cancelling the current normal-path submission; its original batch loop does not reread it. Only GL mode 4 draws; other primitive modes retain element-count/range/fence/return behavior. Normal submission follows 0x1233c–0x12397 in chunks of at most 65,535 elements, using the same raw index pointer and range hints.

Original blend dispatch at 0x122a2–0x122f0 now consumes the mapped GL factors and dirty byte supplied by the separately owned render-state prerequisite. The point byte read at 0x12305 brackets drawing with sizes 2 and 1 (0x12450/0x1232b). Typed accessors expose the native program owner and trailing byte without assuming original offsets. Constructor 0x1f96c initializes the corresponding original trailing byte to zero; the native constructor/layout remain unchanged.

The fence tail at 0x12143–0x121eb and 0x1246a now AddRefs/Releases stream zero, skips usage bits 0x200/0x8 and calls the actual fence provider. Programmable position metadata selects its declared buffer, then adds declared offset, base*stride, **stream-zero offset again**, and MinVertexIndex*stride. Fixed position already includes base, so its tail adds only MinVertexIndex*stride. Sizes use the computed range count. The unusual extra stream-zero offset is preserved, not normalized. CPU scratch remains owned by its existing allocator, and submission finishes before cleanup. No borrowed COM ownership or packet lifetime was changed.

## Native boundaries and remaining gap

The licensed-cache option and explicit `D3D_PROG=0` approximation remain authoritative. The CPU approximation keeps its existing matrix, texture/lightmap, color-order and state policy; it now shares range submission, point and fence orchestration. Extended ARB declarations retain their existing typed array setup and cleanup, with signed widened base-pointer arithmetic. Existing initialized device/packet storage, color scratch and null/malformed declaration adaptations remain. Invalid/null buffer and primitive inputs retain bounded native handling; an empty special-index span does not perform the original unconditional first-index read into potentially unreadable/indeterminate storage.

The direct CPU/extended paths change depth enable/function/mask, cull/fog/light enables, alpha enable/function, color mask/current color, blend factors, program enables/bindings, modelview/projection, units 0/1 texture matrices, texture targets/bindings/combiners, sampler state and raw client-array selection. Normal render setters can return on unchanged D3D cache values; matrix providers honor dirty bytes; COpenGL also compares blend/program/combiner/matrix/array caches. Complete restoration across that boundary is not proved. Program/blend invalidation is explicit. After either direct replacement runs, an owned `directStateDirty` byte preserves the source base's affected CPU/ARB routing until Init/Reset frees stream state; it prevents a new transition into normal fixed providers with dirty direct state. This deliberately leaves the affected old route in place. The older ARB helper's ordinary packet branch also retains its own draw-byte timing, and it has not been certified by the new normal driver.

The row therefore remains unchecked. Closing it requires establishing direct-path server-state restoration and cleanup, then safely removing that routing boundary. A partial helper comparison is not whole-function equivalence. Nonzero-base driver consequences, point-byte nonzero behavior, fence reuse and the new ordinary fixed/program path were compiled and reviewed only, not exercised here.
