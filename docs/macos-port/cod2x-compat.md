# CoD2x compatibility and remaining gaps

The comparison target is upstream `callofduty2x/CoD2x` main at `f0db15cf2be98b6bf5621a4a2076998cdb600c4b` (2026-11-12), version **1.4.7.1-test.1, revision 7**. Its latest release is **v1.4.6.8, revision 6**, 49 commits earlier. Read the pinned files with `git show f0db15cf2be98b6bf5621a4a2076998cdb600c4b:<path>` in the reference checkout; its working branch is older. Upstream has no license permitting source transplantation: this port implements behavior independently.

**The native CoD2x engine now implements revision 7 and announces 1.4.7.1-test.1.** The client decodes the additional player information and implements spectator/demo x-ray, health and head information on the shipped OpenGL renderer. Its revision passes both the current upstream minimum of 7 and released 1.4.6.8's minimum of 6. The native server requires 7, as current upstream does. Real native revision-6 and revision-7 dedicated servers pass all 12 tested admission decisions. The final native client joined our revision-6 and revision-7 servers. Stock-server competitive, text and vMix scenarios ran; revision-7 default spectator health, automatic recording/upload and actual demo playback ran too. Film brightness matches the upstream formula exactly across three full frames; the matched-settings replay agrees with Original in all but one pixel across five views. This document does not declare release readiness or complete game parity. Authentication, passwords, bans, pure files, match credentials and proprietary protection remain separate from the revision gate.

“Source compared” below describes the cited branch/formula/registration only. “Scoped check” means a named existing fixture or loopback case ran. Neither means every game scene, device or remote service was verified. Replays/build status belong in the final parity-fix evidence and release verification; this matrix must not turn a successful build or one joined server into a full-parity claim. Paths prefixed U are from the pinned upstream `src/`; N paths are native `src/PC/` unless `platform/`, `unix/`, or `Mac/` is specified.
