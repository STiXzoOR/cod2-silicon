# Renewed server tail annotation verification

A fresh disposable-project run passed the prospective verification contract for
one server tail annotation. This is accepted preflight evidence, not an accepted
generation change or native behavior change. Generation 15 remains the baseline.
The earlier strict replay failure remains a failure under its original contract.

The temporary change applies one `CALL_RETURN` annotation to the existing jump
from `SV_ConnectionlessPacket` into `SVC_Info`. Original bytes stay unchanged.
The prior bounded instruction-execution evidence supports the transfer; this run
measures its decompiler and metadata consequences. It does not execute either
complete server function or establish native ABI equivalence.

The prospective policy was frozen before execution. Final status, successful
diagnostic, complete C, non-attempt fields and evidence bindings must match the
reviewed expectation. Earlier attempts may differ within the unchanged 30/90
second budgets and 64 MiB payload limit. Every raw attempt remains preserved in
an exhaustive operational ledger. This differs explicitly from the historical
strict policy; it does not retroactively accept the earlier failed run.

The parent executed comparator controls with 29 effective rejections, complete
raw/derived binding controls, and three fresh JVM failure controls. Throwing
before annotation, returning without a completion receipt and a missing script
all stopped before annotation or later stages. A sole driver script checks each
stage's completion before starting the next, addressing the observed headless
behavior that otherwise continued after an earlier script failed.

The fresh application completed all 554 affected-function probes, all 8,115
status records and all 7,481 C outputs, followed by one complete final structural
and recursive-data snapshot. Raw execution records remain immutable. Separately
derived records bind to the actual final snapshot, with every field's before and
after value recorded and checked against the corresponding evidence.

evidence digests change. Across 619,351 instruction records and 389,849 references,
exactly the annotated instruction record and its reference record change, with
the frozen call/discovery consequences. Stored function bodies, signatures,
variables, symbols and both history ledgers remain unchanged. All 4,621 region

qualification covers the process-generated `/undefined` singleton identifier at

177 intended sites disappear, and all 25 remaining cleanup sites stay unresolved.
The inferred return type change and omitted displayed call arguments also remain
unresolved. Neither these counts nor successful export establish source closure.

A separately authored parent audit compared all complete C/status records and
