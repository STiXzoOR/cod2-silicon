# F1 missile branch corrections — 2026-10-24

This bounded batch corrects nine confirmed differences in `g_missile_mp.c`
under `COD2_X64`. It does not claim whole-module reconciliation or replay
parity. The original inactive source is preserved.

## Mac authority and changes

Read-only Linux 1.3 source comparison supplied candidate locations. Each
change was independently checked against the Mac 1.3 i386 binary; no reference
source, assembly, or decompiler output was copied into the repository.

- `G_ExplodeMissile`, `0x1c9513` and `0x1c9696`: airborne smoke waits according
  to `WeaponDef.offhandClass` at original offset `0x84`, not the projectile
  explosion event type. The event check at `0x1c95f1` still uses
  `projExplosion` at `0x390`. The existing absolute `nextthink = 50` behavior
  is retained.
- `G_BounceMissile`, `0x1c9ffc–0x1ca004`: positive speed and a nonpositive
  velocity/normal dot product apply damping. Tangent impacts now receive the
  parallel bounce coefficient instead of retaining full speed.
- `G_RunMissile`, `0x1ca286` and `0x1cabe0`: movement below `0.001f` skips
  tracing and runs think directly. The constant was decoded from literal
  address `0x326210`; equality proceeds with tracing.
- `G_RunMissile`, `0x1ca598–0x1ca5bc`: grenade ground probing occurs after
  unobstructed motion, or after a fractional impact with upward normal above
  `0.7f`. Wall impacts do not request that probe.
- `G_RunMissile`, `0x1ca708–0x1ca720`: ground-probe vertical correction changes
  trajectory base Z at original entity offset `0x20`, not `origin2[0]`.
- `G_RunMissile`, `0x1cacaa–0x1cacca`: grenade trigger damage receives explosion
  inner damage (`WeaponDef + 0x37c`), not the explosion radius.
- `G_RunMissile`, `0x1ca971`: rocket destabilization selects projectile weapon
  type (`WeaponDef + 0x78`), not weapon class.
- `G_RunMissile`, `0x1ca988–0x1ca99f`: destabilization waits through the
  deadline and runs only when the current time has passed it.
- `G_RunMissile`, `0x1ca9de–0x1ca9f7`: perturbation uses
  `destabilizationAngleMax` (`WeaponDef + 0x5a8`), converted to double,
  multiplied by double `0.017453292519943295` from `0x340c28`, then narrowed
  to float before `tanf`. It no longer reads ADS aim pitch.
