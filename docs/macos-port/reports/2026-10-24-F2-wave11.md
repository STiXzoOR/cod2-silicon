# F2 lighting, material utilities and blur integration

Baseline `06275b3`. Lighting registration now falls back to `light_dynamic`
and prints the original loaded-definition list header. The light loader
returns NULL after a missing requested file instead of performing its own
fallback. Material picking rejects startsolid traces and uses the original
unsigned surface-index comparison, preventing the default-surface read before
`infoParms`. Fresnel evaluation clamps its refracted sine before `asin`,
restoring finite total-internal-reflection output.

Blur now resolves each outgoing target, applies its viewport dimensions,
uses the full extent of native textures and composes the result upright.
Below the original minimum radius, it filters at that minimum and reduces
blend alpha; larger requests retain full alpha. The diagnostic sequence
separately demonstrated each defect. This repairs the black-scene defect
already present before wave10; it is not an original-capture parity claim.

The model-surface unit found no valid-input change to make. Its paired index
copies, blended UV omission and weight scales match Mac instructions. Loader
comparison confirmed odd-triangle padding. Malformed input and unordered
floating-point limits are recorded in the module reports rather than silently
classified as equivalent.
