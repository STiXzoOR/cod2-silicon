# R3: JPEG candidate through the real decompiler protocol

The [frozen pre-action provenance candidate](2026-10-23-reconstruction-R3-jpeg-preaction-provenance.md)
passes a bounded Ghidra Java/native protocol campaign and a fresh parent replay.
The candidate recovers the original JPEG function's six ordered switch slots,
including duplicate destinations and the default. All nine previously accepted
switch contracts remain exact. This does not install the candidate or promote
a reconstruction generation.

Each campaign freshly builds all 80 `ghidra_opt` protocol objects with the
recorded flags. The complete source reconciliation permits exactly the four
previously frozen C++ file deltas; no new C++ semantics are introduced here.
Complete private distributions isolate accepted and candidate tools. Actual
child-process executable paths and binary hashes are captured through the
process API, independently of factory-path expectations.

Nine actual original functions run through each tool, including the JPEG target
and the owners of all nine retained switch contracts. The accepted tool leaves
the JPEG switch unresolved. The candidate's recovered mapping is independently
bound to original Mach-O table bytes, its PC thunk and default branch. The other
eight functions have identical complete C, result records, high Pcode and CFG;
their full debug documents also remain equivalent under the prospectively
allowed tool/run context paths. Stored metadata and source-project hashes remain
unchanged. The retained malformed console samples' owners are included; the
current accepted generation's export/554 ledger contains no failed status to
add as another failed sample.

Six exact raw-code memory fixtures also run through both tools. Both no-write
positives recover six slots. All four write counterexamples remain explicitly
unresolved at genuine indirect sites, with no false complete six-slot table.
Their writes survive in the protocol output: this is real protocol refusal
coverage, not a claim that the console's dead-code-erasure trace recurs here.

All 30 probes in each campaign complete on their first 30-second attempt, and
all 30 full debug documents parse. Full outputs, inputs, process receipts and
failed harness attempts are retained. The worker corrected a private project
directory permission before the successful campaign and corrected a comparator
that incorrectly required high `BRANCHIND` after an explicitly unresolved site
became `CALLIND`. Neither correction changed C++ semantics or the frozen
acceptance contract. The parent's independent checker also retained and fixed
an address-format comparison that assumed leading zeroes in high Pcode.

Parent checks independently validate all complete outputs against the worker,
all process path/hash bindings, the original table/thunk/default bytes, the
retained switch mappings and all four negative sites. Source and tool adoption
review and a broader frozen regression/application campaign remain required.
No original JPEG whole-function execution or global source closure is claimed.
