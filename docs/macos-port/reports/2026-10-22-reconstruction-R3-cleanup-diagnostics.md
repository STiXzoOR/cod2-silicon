# Cleanup diagnostic reconciliation

Accepted after an independent parent replay and supplemental original-byte audit.
All 25 non-server cross-body high-Pcode sites are explained as conditional
compiler-cleanup paths. Zero diagnostics are eliminated. No function storage,
analysis generation or native production behavior changes.

The ledger retains eleven stored objects across three original function extents:
MacDisplay::Initialize, Optimize and D3DXCompileShader. Original symbol extents,
frame records and exception tables agree with the existing storage partition.
Every diagnostic has a recorded path from an exception-table landing pad and
from its requesting fragment, with explicit normal-return and frame conditions.
These paths do not make the internal fragments ordinary callable functions.

The fresh parent replay reconstructed all 15 semantic artifacts exactly from 95
pinned inputs. Independent LLVM decoding checked 35,539 instruction boundaries
covering 152,177 original bytes and 33 external incoming instruction sources.
All eight specified comparator mutations were rejected; the unchanged baseline
and ineffective-mutation check passed. The replay took 131.42 seconds.

A separately authored parent audit independently derived the 25-site domain from
the original accepted probes. It retained all 2,279 incoming reference records
and decoded all 2,239 control-transfer targets directly from original branch
displacements. The remaining 40 records are 31 analyzer DATA associations and
nine original symbol-table fields; none is promoted to an executable edge.
The audit checked 249 direct-branch and 1,498 conditional normal-successor path
steps, and every ordered function/region history digest. These step counts
include repeated edges across the recorded paths.

The parent checked complete source, worker replay and parent replay inventories,
including actual hashes and read-only file modes. Failed worker attempts remain
preserved. The parent's first supplemental audit incorrectly required a probe
function record to equal an audit record containing an additional symbol ID.
The corrected audit checks the complete probe against its accepted source and
requires exact shared fields plus that single explicit format difference.
The original failed audit is retained.

Optimize retains its 57-state abstract proof conditions. Display retains its
finite original-instruction execution with modeled imports. D3DX retains its
static structural and argument-copy qualifications. This reconciliation does
not rerun those historical execution campaigns or establish actual exception
delivery, arbitrary cleanup-callee behavior, live reachability, whole-function
or native equivalence. Native tests were deliberately omitted because this is
a static evidence and documentation change.
