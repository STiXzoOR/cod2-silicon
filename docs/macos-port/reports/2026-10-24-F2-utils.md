# F2 renderer utility reconciliation

Baseline `314d0e6`, behavior_changed: true. Three native-only corrections restore
original Mac1.3 behavior in r_utils.c.

R_PickMaterial (0xf56e6) rejects either allsolid or startsolid: Mac compares
the adjacent two bytes as a word at 0xf5769. The reconstruction tested only
allsolid, so a ray starting inside solid geometry could return a material.
The surface type subtraction is followed by unsigned JA at 0xf57db/0xf57de;
casting the computed index unsigned restores the default-surface case when
the type bits are zero. Previously index-1 read before infoParms. The Mac
default literal at 0x250ff4 is ^1default^7. Remaining finite trace checks,
material copying, bounds markers, content/flag formatting and table traversal
match the original. Native CM_BoxTrace remains slot 86; the Mac slot 87
difference is intentional native refimport layout, confirmed with offsetof
and an unchanged dispatch control. No callback/layout change was made.

FresnelTerm (0xf59f6) clamps the refracted sine to 1 before asin when it exceeds
1. Mac0xf5a48 loads the double 1.0 at 0x340bf0 and passes it on the greater
branch; the reconstructed self-assignment retained the out-of-domain value.
The lower literal0x340c58 is -1.0. Restoring the upper clamp makes the finite
total-internal-reflection case (1.5,1.0,0.5) return 1 rather than NaN. Existing
float division followed by double trigonometry and final float clamping stay.
The screenshot Fresnel-alpha generator calls this function with its supplied
indices; no broader libm parity claim is made.

Bounded comparison also covered R_HashAssetName0xf5578, R_HashString0xf55ae,
R_CullPointAndRadius0xf55e6, R_ConvertColorToBytes0xf568c and
R_ValidXModelName0xf59a6. Signed byte hashing with multiplier 119+i,
case-bit folding, plane sum/order, ARGB truncation and xmodel prefix/length
checks match for their ordinary bounded inputs. Overflow in arbitrarily long
hash strings and out-of-range float-to-byte conversion are not newly claimed
defined or exercised. No validation or clamping policy was added there.

Existing tests were searched for these functions; commands.c stubs color
conversion and does not exercise material picking or Fresnel. Added one
production-source fixture utils.c and runner run_utils.py. Before source edits,
the dispatch control passed, default-material lookup produced an ASan global
buffer overflow, startsolid failed the expected rejection, and total internal
reflection failed the finite/unit result assertion. After the three fixes,
all four cases pass stock and CoD2x ASan/UBSan. The final fixture corrected its
trace callback return type to match the native header; no production callback
code was changed. The final fixture was also run against --baseline 314d0e6
in final-baseline: the same three failures and passing dispatch control recur. Four existing strlen-to-int warnings remain in production.
