# F2 reference viewpoints — 2026-10-26

Fresh CoD2x OpenGL captures are visually close to the frozen Windows CD 1.3 /
CoD2x 1.4.6.8 reference views under D9VK and mtld3d. This comparison found and
verified a real [TGA channel repair](2026-10-26-F2-screenshot.md); it does not
certify full renderer parity.

## Method

Two separate native runs captured Toujane courtyard, rooftop and sky at
1280×720, FOV 80, picmip/bump/spec 0, manual picmip, AA 1, gamma 1, with HUD
and weapon hidden. Native draw traces verified camera origins exactly:
(2569,2274,182), (3051,2178,221) and (3051,2178,351). Native yaw is 180 for
courtyard/rooftop; the reference console prints integer yaw 179. Native sky
pitch is -85; reference sky pitch was produced by holding lookup and was not
independently measured. Those limits prevent a strict matched-camera claim.
The first native attempt had a transient 0.16-unit camera-height discrepancy
and was rejected. Waiting for noclip to take effect produced the accepted poses.

All 28 stock IWD hashes match both reference installations. Each reference
also has `iw_CoD2x_01.iwd`, containing radar images/materials and a main menu;
that extra archive is absent from native. HUD is hidden in these captures.
No archive content or game image is committed.

Pillow decodes each uncompressed TGA to RGB; NumPy computes full-frame absolute
difference and RMSE on all 1280×720×3 byte values. There is no crop, alignment,
channel remapping, color correction or excluded pixel mask. Each native run
uses a private home directory and the shared read-only shader cache. The VM
was suspended throughout native runs and restored to its previous running
state afterward. No guest commands, authentication changes or fresh Wine run
were used.

## Measurements

Values are on the 0–255 channel scale; each cell is MAE / RMSE.

| View | Native repeat | D9VK reference | mtld3d reference |
| --- | ---: | ---: | ---: |
| Courtyard | 0.0264 / 0.2441 | 0.5712 / 3.2000 | 0.7940 / 3.3469 |
| Rooftop | 0.0009 / 0.0470 | 0.6677 / 4.4077 | 0.7395 / 4.4775 |
| Sky | 0 / 0 | 0.0723 / 0.2919 | 0.0648 / 0.2751 |

Both runs capture all three poses and exit zero. Decoded courtyard pixels and
4× difference images were inspected. Remaining courtyard differences cluster
around sky openings, distant building edges and some ground/wall boundaries.
The comparison does not identify their cause or assign a pass tolerance after
seeing these results. Low averages alone cannot exclude localized errors.

Before repair, native TGA files had red/blue reversed, producing courtyard MAE
10.4478 against D9VK while native JPEG appeared correct. Comparing native TGA
with its JPEG gave MAE 10.41, dropping to 1.16 only with diagnostic red/blue
remapping. The remapping was used to diagnose serialization; the measurements
above use newly captured, fixed TGA files with no such transformation.

## Limits and evidence

These are three static Windows-translator reference views. Original Mac runtime
captures, moving scenes, particles, animation, all materials, every renderer
state and other maps remain outside this comparison. The full faithful plan
and its unexplained-difference criteria remain active.

Private evidence: `~/Library/Application Support/CoD2-native-decomp/F2-captures.noindex/`,
including `native-fixed-a`, `native-fixed-b`, `fixed-results.json`,
`metrics-fixed.json`, `asset-comparison.json` and `compare-fixed.py`. Frozen
references are `REF-B.noindex/d9vk/normal3` and `REF-B.noindex/mtld3d/normal2`.
