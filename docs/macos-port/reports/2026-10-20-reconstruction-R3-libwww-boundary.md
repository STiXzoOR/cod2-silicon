Mac multiplayer downloader. Raw compilation-unit and function records identify
881 libwww functions. All remain in the reconstruction inventory; identifying
the library does not establish equivalence to the native SDK libcurl replacement.

61 direct calls and 607 DATA references. Including function interiors yields
920 crossing references. The ledger also retains 15,832 outward references
and 472 unresolved computed transfers. Data pointers and debug-symbol records

complete object ownership.

Forty-five finite cases execute the original wrappers and selected query and
printing helpers. They cover initialization, cancellation, pending and terminal

userinfo handling. The runs execute 2,170 instructions at 489 unique addresses

Existing downloader tests primarily mock the backend while exercising callers.

callers. Twelve source-backed obligations distinguish that adaptation from
remaining differences and unknowns: progress/display updates, userinfo handling,
file opening and cleanup, terminal errors, MOTD state and callback lifecycle.
