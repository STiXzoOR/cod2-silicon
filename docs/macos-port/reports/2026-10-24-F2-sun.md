## Findings and comparison

Authority: original Mac 1.3 multiplayer i386 binary. Fourteen named bodies
were extracted individually with `otool -arch i386 -tV -p`; each subprocess
was stopped at the next symbol label. Private evidence is in
`~/Library/Application Support/CoD2-native-decomp/F2-sun.noindex/`. Ghidra
`ddb08.c` and `de038.c` were reading aids for the two draw routines; changes
were checked against instructions. No reference source or assembly is added
to the repository.

| Functions | Result |
| --- | --- |
| `R_GetSundvarsSize`, `R_RegisterSunDvars` | Compared unchanged: 21 names, material names, defaults, ranges, and flags match. |
| `R_Cmd_LoadSun`, `R_Cmd_SaveSun` | Control flow matches; fixed usage, cheats-disabled, and world-not-loaded messages to Mac 1.3. Save still serializes 21 dvars into 8192 bytes and writes the resulting string length. |
| `R_FlushSun` | Compared unchanged: clears seven dynamic values across four states, preserves query/error/cumulative fields. Existing WS38 typed stride remains. |
| `R_SetSunFromDvars` | Compared unchanged: material track 6, half flare sizes, double cosine with radians constant, six rounded millisecond durations, direction conversion, valid flag. Native inline dvar vector representation retained. |
| `R_LoadSunThroughDvars`, `R_LoadSun` | Compared unchanged: missing-file warning/return, conversion only after successful parsing, free after either parse result; native full-struct zero, last slash/backslash, 64-byte filename, first-dot truncation, skip empty basename. |
| `RB_CalcSunSpriteSamples` | Fixed device access to native `DxGlobals.device`. Retains first state's first query, begin/end scene, 16×16 white draw, pending polling, and 256 samples on query error. |
| `RB_SetTessQuad`, `RB_SetTessQuadDx7` | Fixed native tess counters/pointers. Retains indices 3,0,2,2,0,1; UVs, normals, tangent/binormal, color, and 64/36-byte native vertex formats. |
| `RB_TessSunBillboard` | Restored the missing color argument. Typed world/backend/dvar access; retains DX7 perspective divide versus DX9 homogeneous coordinates, identity matrices, and depth bias. |
| `RB_DrawSun` | Fixed native fields, the global additive-material lookup, query billboard width/height denominators and color. Preserves CPU screen-area visibility and trace, alternating queries, sample normalization/error retention, accumulated visibility, and both sprite paths. |
| `RB_DrawSunPostEffects` | Fixed native fields, global glare/blind-material lookup, and billboard color propagation. Equal nonzero timestamps now produce zero elapsed time. Preserves flare size/alpha interpolation and independent blind/glare fade state and packing. |

Specific instruction anchors:

- `RB_CalcSunSpriteSamples` `0xde0f3–0xde100` loads the device field; the
  old native path read the ILP32 byte offset 8, which is `d3d9` in the native
  structure. Query vtable slots 6/7 and scene slots 41/42 remain correct.
- `RB_SetTessQuad` `0xde244–0xde2be` reads vertex/index counts and the index
  pointer; native tess indices remain at their established layout location,
  but subsequent pointer-bearing members move. The old raw counter offsets
  were not valid native offsets. The fixture uses real `materialCommands_t`.
- `RB_TessSunBillboard` `0xde505`, `0xde65e`, and `0xde984` carry the color
  argument into either vertex writer. The old source instead converted the
  width to an integer color and never passed the caller's color.
- `RB_DrawSun` `0xdf0e0–0xdf0e5` reads `rgp.additiveMaterial`, not a world
  member. `0xdf135–0xdf160` passes width `16 / backEnd.width`, height
  `16 / backEnd.height`, and packed color `0x000000ff`. The original source
  exchanged those denominators and omitted color. The final fixture checks
  a nonsquare 640×480 viewport.
- `RB_DrawSunPostEffects` `0xdeb40–0xdeb42` branches to subtraction when
  previous time is **less than or equal** to current time. The old `<=`
  reset condition incorrectly advanced a repeated timestamp by 10 ms.
  `0xdeeb0–0xdeebf` reads `rgp.glareBlindMaterial`, not a world member.
- Command strings were checked at binary addresses `0x251aac`, `0x251af0`,
  `0x251b20`, and `0x251b50`. Numerical constants were read from their mapped
  Mach-O segment locations, including 480/640, ±0.001, and radians-per-degree.

A single `COD2_X64` implementation branch in `rb_sky.c` keeps the original
legacy body intact. It avoids dozens of per-access conditional offset
substitutions. Public entry points, material techniques, renderer command
flow, query interfaces, and native state structures are unchanged. The
existing direct native `CM_BoxSightTrace` call remains.

## Tests and evidence

Existing material inspected: WS38 sun stride/clear report and WS12 sun-query
import mapping; `tests/lp64/renderer/run_water.py` for production fixture
conventions. No tracked sun fixture was found. WS38 describes temporary
private sun-state probes; those were not rerun or represented as this unit's
new evidence. No existing tests were changed or run unchanged.

The new fixture compiles the real `rb_sky.c` and `r_sky.c` bodies using the
selected engine compile database, with assertions, ASan, and UBSan enabled.
Recording callbacks observe emitted native vertices/indices, materials,
colors, matrix-stack balance, traces, query calls, and dynamic state. They do
not replace the production rendering/fade calculations. `R_LoadSunThroughDvars`
is stubbed for command-routing checks; file loading itself is covered here
by instruction comparison only.

Before production edits, the seven initial cases all failed: quad counts,
sprite draw, visibility, query draw, sample device dereference (UBSan null
load), flare draw, and fade. `red.log` and `red/*.log` retain those failures.
The complete instruction pass then corrected the query oracle to the Mac
16-pixel footprint and `0xff` color, exposing a red query case against the
first native draft (`query-red.log`). The four command-message expectations
also failed before their production edits (`messages-red.log`).
